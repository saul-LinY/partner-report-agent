Partner Report 项目启动速查
============================

项目目录：

  cd /Users/saul/PROJECT/partner-report-agent


首次启动或数据库重建后
----------------------

npm install
docker compose up -d postgres
npm run db:migrate
npm run db:seed
npm run dev

`npm run dev` 会同时启动 API、Web 和 Worker，终端需要保持运行。


日常启动
--------

  docker compose up -d postgres
  npm run dev


访问与检查
----------

  Web: http://127.0.0.1:4311
  API: http://127.0.0.1:4310

  curl -sS http://127.0.0.1:4310/health
  curl -sS -o /dev/null -w "%{http_code}\n" http://127.0.0.1:4311/

默认账号：

  saul@laien.io
  123456


停止项目
--------

先在运行 `npm run dev` 的终端按 Ctrl+C，再执行：

  docker compose stop postgres
