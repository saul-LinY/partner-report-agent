# weekly report 原生 App 本地使用验证

本文为 2026-10-29 的历史验证记录；当前工作流以 [App 采集工作流](APP_COLLECTION_WORKFLOW.md) 为准。

日期：2026-10-29。当前交付为 macOS SwiftUI + AppKit 原生应用，源码位于 `apps/macos`。默认运行真实本机模式，示例数据仅在显式 `--demo` 时使用。

## 已接通的真实流程

- 启动及每分钟自动发现本机项目，也可手动刷新。发现阶段使用工具的目录／会话身份元数据，不为待确认项目提取提问、回复或标题。
- 以 Git 根或登记的文件夹组织项目，临时目录忽略。同名但不同目录分别确认。
- 本地确认是这轮历史测试的权限来源，与远程系统无关。已授权验证的 `partner-report-agent` 可显式传入启动参数；其他新项目默认待确认。
- 允许后才进入首页，用随 App 打包的独立 Rust 组件读取真实会话；来源头像、时间、模型、未完成状态均根据实际记录显示。
- 停止本地采集后移除首页正文，权限结果可在重启后恢复。
- “立即上传”只准备真实的本地待传队列，保持待上传状态，不向系统发请求，也不伪造成功记录；重复准备不新增相同批次。

## 构建及测试

Xcode 27 构建通过；当前最低目标 macOS 14。默认窗口为 1120 × 840。图标为打包的本地资源，UI 没有依赖网页或 WebView。

19 项 XCTest 测试通过，包括项目／Agent 范围筛选、正文搜索、未完成状态、设置持久化、损坏状态文件保护、真实格式元数据发现、非 Git 目录登记、临时目录排除、本地允许后才读取、撤销移除正文、同名项目不自动继承权限、真实标题优先、标题只从已允许范围读取，以及每天／每周频率和旧设置迁移。

本轮界面修正：会话优先采用原生标题；当前项目 131 个会话中找到 126 个原生标题（Codex 125、OMP 1），没有原生标题才回退。Agent 选择器改为固定图标尺寸的 SwiftUI 弹出列表；上传频率使用每天一次／每周一次两个直接选择按钮，周频率可选星期。系统地址字段已从界面和用户偏好模型移除，仅保留内部构建配置。

另外运行了独立的真实本机流程检查，使用独立私有状态目录，允许范围仅为 `partner-report-agent`，不改变日常 App 的其他本地确认：

实际 UI 已启动并展示真实会话。截图由本 App 自身视图渲染生成，位于 `.local/weekly-report/live-screenshots-v2`；包含本机私有内容，不纳入版本库。

真实流程检查脚本：`apps/macos/scripts/local-smoke.swift`。其结果与待传原文位于 `.local/weekly-report/real-workflow-check`；测试状态不复用 App 日常的 Application Support 状态。正文文件权限为 0600，所在目录为 0700。

## 仍未接入

- 系统账号登录、远程项目审批及服务器上传（当时未接入）。
- 系统级登录自启注册和更新源，当前相应开关只保存本地偏好。
- 后台按上传频率自动向外部系统投递；本版手动准备队列真实可用。
- 已验证格式以外的桌面独立存储、云端／远端历史和缺少可验证项目元数据的旧记录。8 种保留工具已在本机验证正式回复；最新全量结果与来源边界见来源覆盖矩阵。

默认不读取未确认项目的正文，但文件读取定位字段仍受 JSONL 混合记录和 SQLite 页预读的限制，不声称实现字节级物理隔离。

Antigravity CLI／桌面漏采修复、刷新触发及各来源未完成项见 [来源覆盖矩阵](AGENT_SOURCE_COVERAGE.md)。
