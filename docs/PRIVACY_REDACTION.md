# 隐私信息隐藏

成员的会话在离开电脑、进入中台之前，会先隐藏两类内容，再加上成员自己标记的内容。其余文字、空白和换行保持原样。

| 类别 | 例子 |
|---|---|
| 凭证：拿到就能访问系统的值 | `sk-…`、GitHub / Slack / AWS 风格令牌、`Bearer …`、私钥块、`password=…`、32 位以上十六进制串、40 位以上大小写数字混合长串、「口令是……」这类写在句子里的口令 |
| 能识别人或设备的信息 | 邮箱、手机号、IP 地址（含端口）、网址、本机文件路径 |
| 成员自己标记的内容 | 在会话里选中文字后右键「隐藏所选内容」，或在「隐私说明」页添加 |

隐藏后统一显示为 `[已隐藏]`。

## 三层

| 层 | 位置 | 作用 |
|---|---|---|
| 成员标记 | App，`AppStore.hiddenTerms`，保存在本机状态文件，重新绑定后保留 | 相同文字在所有会话、所有后续上传中都被隐藏 |
| App 上传前 | `apps/macos/Sources/Core/SecretScrubber.swift`，在 `CollectorPackage` 打包时处理 | 隐藏的内容不离开成员电脑 |
| 服务端入库前 | `redactSessionText`，在 `POST /v1/collector/uploads/:id/parts` 里，校验分片完整性之后、写入 `collector_upload_parts` 之前 | 旧版 App 和 App 漏掉的内容也不落库（成员标记的内容服务端不知道，只在 App 层生效） |

App 和服务端用同一套自动规则（`packages/contracts/src/privacy.ts` 的 `redactSensitive`），只改写标题、提问和回复三类文本，其余字段（编号、时间、模型名）原样保存。分片校验值描述的是 App 发出的内容，服务端不会再用存储的内容重新计算它。

## 在 App 里怎么看到

「项目会话」页把将被隐藏的内容标红，顶部提示「已标红 N 处隐私信息，上传时自动隐藏」。本机显示的原文不会被修改。选中文字后右键「隐藏所选内容」即可新增标记；「隐私说明」页可以查看、添加和移除已标记的内容。

标记新内容后，包含它的会话会重新变成「未上传」，下次上传会带上隐藏后的版本；已排队但未发出的旧包会作废并重新打包。公司系统里更早的版本不会因此被删除。

## 规则细节

- 凭证规则见 `privacy.ts`；句子里的凭证：关键词之后、同一分句内（遇到逗号、句号、分号、换行停止，最多 40 个字符）出现的 6 位以上字母数字串，贴着斜杠的路径片段不算。
- 网址：以 `http://` 或 `https://` 开头的 ASCII 网址字符，遇到中文或空白停止，末尾的标点不算在内。
- 邮箱：`名字@域名.后缀`，紧贴中文也能识别。
- 手机号：中国大陆 11 位（`1[3-9]` 开头），可带 `+86`；前后紧贴数字的长数字串不算。
- IP：IPv4，每段 0–255，可带端口；版本号如 `1.2.3.4.5` 不算。
- 本机路径：`/Users`、`/home`、`/var`、`/private`、`/tmp`、`/Volumes`、`~/`、`C:\Users\` 开头，到空白、括号、引号或中文标点为止。相对路径（如 `src/tmp/x.ts`）不算。
- 成员标记：按字面匹配，区分大小写；重叠的标记合并成一处；至少 2 个字，最多 500 个字。

已知的取舍：40 位十六进制会被当作密钥，所以 git 提交哈希也会被隐藏；规则只覆盖上面这些写法，不能保证识别所有隐私信息。IPv6、座机号、国外手机号和不带 `http` 的域名目前不识别，可以用成员标记补充。

## 两端一致

`packages/contracts/src/privacy-vectors.json` 是两端共用的测试向量，TypeScript（`privacy.test.ts`）和 Swift（`SecretScrubberTests`）都必须对每条给出完全相同的输出。规则里不用 `\b`、`\w`、`\d`，因为 JavaScript 把中文当作非单词字符、Swift 的正则把中文当作单词字符，Swift 的 `\d` 还接受非 ASCII 数字，边界和字符类一律用 ASCII 写出。改规则时先改向量，再改两端。

## 已存数据

`apps/api/src/redact-stored-sessions.ts` 把已经入库的会话也清一遍。默认只统计并打印脱敏后的上下文，不写库：

```
cd apps/api && node --import tsx src/redact-stored-sessions.ts          # 空跑
cd apps/api && node --import tsx src/redact-stored-sessions.ts --apply  # 写回
```

写回不可逆：原文只剩成员本机那一份。由工作卡、项目简介等派生出来的文本不在这个脚本范围内。
