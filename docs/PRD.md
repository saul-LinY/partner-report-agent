# Partner Report 当前产品定义

## 目标

在不上传完整 Codex 对话的前提下，采集用户允许项目中的有效 Session，按周生成可确认、可修改、可追溯的项目工作卡片，并为团队汇总提供结构化素材。

## 用户端

macOS“工作看板”是唯一用户操作入口，只包含三个页面：

- 采集权限：列出全部新旧项目，支持批量允许、拒绝和后续修改。
- 工作卡片：默认仅展示最新一期；每个项目每周一张卡片；支持确认、忽略和自然语言修改。
- 设置：展示当前 Mac 的连接、最近采集、下次运行和连接恢复申请。

桌面组件固定为中尺寸，只承担状态展示：左侧显示当前 Mac 的采集状态、上传和运行信息，右侧显示周一至周日每日有效 Session 数并突出今天。组件不执行审批。

产品不提供个人周报，也不通过飞书进行绑定、授权、审核或交付。

## 数据与版本

- 一名用户当前只考虑一台采集设备。
- 首次插件绑定幂等创建官方每日定时任务，用户不管理任务配置。
- 未允许项目只登记匿名项目键、显示名和 Session 数，不读取 Session 内容。
- 工作卡片按自然周生成；新一周创建新卡片，同一周自然语言修改产生 v2、v3 等新版本。
- 应用提供相邻版本的修改前后对照；已确认版本不可被静默覆盖。
- 旧周卡片保留在服务端用于审计和团队汇总，但不出现在应用默认列表。

## 系统职责

- Plugin：发现项目、遵守项目权限、提取单个有效 Session、幂等上传、上报采集健康状态。
- API/Worker：保存权限、按周聚合工作卡片、版本化重生成、冻结确认结果、生成团队汇总素材。
- macOS App：完成用户授权、工作卡片审核修改、连接恢复与状态查看。
- Widget：只读展示本机每日采集状态和本周统计。

## 验收重点

1. 一周始终按周一至周日展示，七天均显示具体数值，今天有明确视觉强调。
2. 权限页可一次修改多个新旧项目，版本冲突不会覆盖新数据。
3. 工作卡片只显示最新一期，并能通过自然语言连续生成多个可追溯版本。
4. 初次绑定后定时任务存在且重复绑定不会重复创建。
5. 运行代码、数据库当前结构、用户页面和文档均不依赖飞书或个人周报入口。
